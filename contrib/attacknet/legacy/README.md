# Legacy Attacknet material

The supported Attacknet interface is the typed Go CLI and the
`testing.stacks.org/v1beta1` API. This directory contains frozen compatibility
and qualification inputs only.

- [`v1alpha1/`](v1alpha1/) contains the retired prototype runtime and its tests.
- Historical release tooling remains under [`../release/`](../release/).

Nothing below this directory is a supported operator workflow or command-line
contract.
