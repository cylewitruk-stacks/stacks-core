The Hacknet operator is installed in namespace {{ .Release.Namespace }} and
watches StacksNetwork resources in namespace {{ include "hacknet.watchNamespace" . }}.

Build the local topology-operator and trusted run-operator images before
installation when using the default image settings:

  contrib/helm/hacknet/scripts/build-local.sh

The installer imports the exact local images into every Docker Desktop kind
node. There is no source-mount controller fallback.

Inspect networks with:

  kubectl get stacksnetworks.testing.stacks.org -n {{ include "hacknet.watchNamespace" . }}
  kubectl get burnchainpolicies.testing.stacks.org -n {{ include "hacknet.watchNamespace" . }}
  kubectl get faultcampaigns.testing.stacks.org,attacknetruns.testing.stacks.org \
    -n {{ include "hacknet.watchNamespace" . }}

No StacksNetwork is created by the chart. After loading a branch Stacks image,
start with examples/minimal-burnchain-policy.yaml and examples/minimal.yaml.
Never use valuable keys in this test system.
